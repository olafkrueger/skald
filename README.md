# Skald

Skald is an AI-assisted web app for exploring and shaping sounds on Behringer synthesizers. It combines hands-on instrument control with a conversational sound-design assistant and an optional learning mode.

## Goals

- **Control the instrument:** Provide a clear interface for the synthesizer's available sound parameters.
- **Describe a sound:** Let users explain a sound in natural language and have AI suggest settings that move the instrument toward it.
- **Learn while creating:** Explain what the suggested parameters do and why they help produce the requested sound.
- **Stay in control:** Make it easy to understand, review, and adjust the resulting settings.

## Project status

Skald is at the project setup stage. The exact Behringer model, hardware connection method, and technical architecture still need to be confirmed before implementation.

## Planned areas

- Synthesizer parameter interface
- Hardware communication and parameter mapping
- AI-assisted sound suggestions
- Explanations and interactive synthesizer learning

## Name

**Skald** is a storyteller: the app helps users describe, discover, and understand sounds.
